# Portal Informasi Klinik Casa Medical Bengkong

Website portal informasi untuk Klinik Casa Medical Bengkong yang menampilkan informasi pasien dan dokumen medis.

## 📋 Fitur

- Tampilan responsif (mobile-friendly)
- Informasi klinik lengkap
- Nomor kontak yang mudah diakses
- Status dokumen dengan verifikasi visual
- Design modern dan clean

## 📍 Lokasi

**Klinik Casa Medical Bengkong**
- Alamat: Komplek Taman Sentosa Indah Blok F no 19 - Kota Batam
- Telepon: 0778-452941

## 🚀 Deployment

Website ini dapat di-deploy menggunakan GitHub Pages:

1. Go to repository settings
2. Scroll ke bagian "GitHub Pages"
3. Pilih branch `main` sebagai source
4. Website akan tersedia di: `https://harisjulianda123-droid.github.io/klinik-portal/`
